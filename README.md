# Deye CYD Monitor

Прошивка для платы **ESP32-2432S028 (CYD, «Cheap Yellow Display»)**, которая показывает состояние гибридного инвертора **Deye** на сенсорном экране 320×240.

> **Только для однофазных гибридов Deye** (серия LP1, батарея 48 В). Трёхфазные инверторы (LP3/HP3) эта прошивка не поддерживает и поддерживать не будет: для них планируется отдельная прошивка.

Устройство по Wi‑Fi опрашивает логгер Solarman инвертора (протокол **Solarman V5**, внутри Modbus RTU, TCP-порт 8899) и выводит данные на экраны:

- **Flow** (главный экран, в стиле панели Deye): четыре шкалы-дуги PV, сети, батареи и нагрузки от 0 до номинальной мощности инвертора, пунктирные линии с бегущими точками по направлению потока, суточные счётчики (выработка PV, куплено из сети, заряд и разряд батареи, потребление дома), напряжение сети, температура батареи. В центре кольцо источников энергии за день (PV, батарея, сеть) с долей «own» и статус связи с инвертором ON/OFF;
- **Battery**: SOC, напряжение, ток, мощность и температура батареи;
- **Grid**: напряжение и мощность сети, мощность нагрузки;
- **Solar**: напряжение, ток и мощность PV1/PV2, выработка за день;
- **Settings**: яркость, таймаут экрана, часовой пояс, Reboot и сброс Wi‑Fi.

Нижней панели вкладок нет: Battery, Grid и Solar открываются тапом по соответствующей шкале на Flow, Settings — тапом по шестерёнке или долгим нажатием кнопки BOOT. Круглая кнопка «‹» в правом нижнем углу возвращает на Flow.

## Совместимость с инверторами

Прошивка разработана и проверена на **Deye SUN-5K-SG05LP1-EU**. Совместимость с другими моделями выведена из карты регистров и на железе не проверялась.

Прошивка читает один блок Modbus-регистров **70…191** в формате однофазных гибридов Deye (суточные счётчики 70–84 и 108, напряжение сети 150, мощность сети 169 и внешнего CT 172, нагрузка 178, батарея 182–184 и 190–191, PV 109–112 и 186–187). Кроме того, ответ отбрасывается при неправдоподобных значениях: напряжение батареи выше 70 В, мощность батареи или одной строки PV выше 15 кВт, ток строки PV выше 30 А. Эти пороги рассчитаны на систему 48 В мощностью до 12 кВт.

### Подходят

| Семейство | Примеры моделей | Замечания |
|---|---|---|
| Однофазные низковольтные гибриды Deye (батарея 48 В) | SUN-3.6K/5K/6K-SG03LP1-EU, **SUN-5K-SG05LP1-EU** (проверен), SUN-7.6K/8K-SG01LP1, SUN-xK-SG04LP1 | Должны работать без изменений |
| Американские split-phase той же серии | SUN-xK-SG01LP1-US | Напряжение сети показывается по одной фазе (~120 В) |
| Ребренды Deye с той же картой регистров | Sunsynk (однофазные гибриды), Sol-Ark 5K/8K/12K | Нужен логгер Solarman. Штатный донгл Sunsynk часто не поддерживает Solarman V5 |

Ограничения для этого семейства:

- **Больше двух MPPT** (старшие модели 10–16K): PV3/PV4 не отображаются, суммарная мощность солнца занижена.
- **Модели 14–16K**: мощность батареи на пике может превысить порог 15 кВт. Такие ответы будут отбрасываться, и показания на экране перестанут обновляться.

### Не подходят

| Семейство | Примеры моделей | Причина |
|---|---|---|
| Трёхфазные низковольтные гибриды | SUN-5…12K-SG03LP3 / SG04LP3-EU | Другая карта регистров (данные в диапазоне ~500–680) |
| Трёхфазные высоковольтные гибриды | SUN-xxK-SG01HP3-EU и др. | Та же карта, что у LP3, плюс батарея 160–800 В не проходит проверку «≤ 70 В» |
| Сетевые (стринговые) инверторы | SUN-xK-G, SUN-xxK-G03/G04 | Нет батареи, другая карта регистров |
| Микроинверторы | SUN600/800/1000G3 и др. | Другая карта регистров, нет батареи |

> ⚠️ На трёхфазном инверторе прошивка может показывать **правдоподобные, но неверные** числа. Ответ корректен по контрольным суммам, поэтому отбрасывается он только тогда, когда значения не проходят проверку правдоподобия.

### Требования к логгеру

Нужен Wi‑Fi/LAN-логгер Solarman (например, LSW-3, LSE), который отвечает по протоколу V5 на TCP-порту **8899** в локальной сети. У некоторых новых логгеров и прошивок этот порт закрыт, с такими прошивка работать не будет. Для настройки понадобятся IP-адрес логгера и его серийный номер (см. следующий раздел).

### Где взять серийный номер логгера

Нужен серийный номер **логгера (Wi‑Fi-стика Solarman)**, а не самого инвертора. Он входит в каждый запрос протокола V5: если номер указан неверно, логгер просто не отвечает. В портале настройки это поле называется «Inverter SN», но вводить туда нужно номер логгера.

Серийный номер логгера состоит из **10 цифр** и обычно начинается с `17`, `21`, `23`, `27`, `29` или `40`, например `2712345678`. Вводится только цифрами, без букв и пробелов.

Найти его можно любым из способов:

1. **Наклейка на стике.** Логгер вставлен в разъём снизу или сбоку инвертора, номер напечатан на его корпусе в строке `SN`. Серийный номер инвертора напечатан на его собственной табличке и сюда не подходит.
2. **Имя точки доступа логгера.** Логгер раздаёт Wi‑Fi-сеть вида `AP_2712345678`, цифры после `AP_` и есть серийный номер. Сеть видна в списке Wi‑Fi на телефоне рядом с инвертором.
3. **Веб-интерфейс логгера.** Откройте в браузере `http://<IP логгера>` (логин и пароль по умолчанию `admin` / `admin`). На странице **Status** номер указан в поле **Device serial number**.
4. **Приложение Solarman Smart.** Выберите станцию, откройте **Устройство → Логгер** и найдите поле **SN**.

IP-адрес логгера можно посмотреть в списке клиентов роутера (имя устройства зависит от прошивки логгера, надёжнее искать по MAC-адресу или по времени подключения). Удобно закрепить за ним постоянный адрес в настройках DHCP роутера.

## Оборудование

- Плата ESP32-2432S028 (CYD): дисплей ILI9341 320×240, тач XPT2046.
- Питание по USB.

## Сборка и прошивка

Проект собирается в [PlatformIO](https://platformio.org/), окружение `cyd`:

```
pio run -e cyd                 # сборка
pio run -e cyd -t upload       # прошивка
pio device monitor -b 115200   # serial-лог
```

## Первая настройка

1. При первом запуске плата поднимает точку доступа **`Deye_Monitor_ESP32_IoT`**.
2. Подключитесь к ней и в открывшемся портале выберите домашнюю сеть Wi‑Fi.
3. Укажите IP-адрес и порт логгера, его [серийный номер](#где-взять-серийный-номер-логгера), Modbus Slave ID (обычно 1), часовой пояс, флаг летнего времени и номинальную мощность инвертора в кВт (например, `3.6`, `5`, `6`; по ней масштабируются шкалы на Flow, по умолчанию 5).

Настройки хранятся в NVS и переживают перезагрузку. Чтобы снова открыть портал (например, сменить мощность инвертора), нажмите «Reset WiFi» на экране Settings: стираются только данные Wi‑Fi, остальные поля портал покажет с прежними значениями. Поведение при пропадании света, перезагрузке и потере сети описано в [docs/behavior_scenarios.md](docs/behavior_scenarios.md).

## Планы

- показ PV3/PV4 для однофазных моделей с 3–4 MPPT (регистры уже входят в опрашиваемый блок);
- пороги правдоподобия для моделей 14–16K.

## Трёхфазные инверторы: отдельная прошивка

Трёхфазные гибриды Deye (SUN-xK-SG03LP3/SG04LP3-EU с батареей 48 В, SUN-xxK-SG01HP3-EU с высоковольтной батареей) будут поддержаны **отдельной прошивкой**, а не профилем в этой. Заметки для неё:

- **Карта регистров** (предварительно, сверить с документацией Deye): батарея 586–591 (температура, напряжение, SOC, мощность, ток), напряжение сети по фазам 598–600, мощность сети 625, нагрузка 653, мощность PV 672–673, напряжение и ток PV 676–679. Всё это читается одним блоком 586…679 (94 регистра). Выработка за день (529) лежит вне этого блока.
- **Пороги правдоподобия** для HP3: напряжение батареи до ~800 В, мощности до 30–50 кВт.
- **Проверка на железе**: нужен владелец трёхфазного Deye, готовый прислать serial-лог.
