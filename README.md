# Deye CYD Monitor

Прошивка для платы **ESP32-2432S028 (CYD, «Cheap Yellow Display»)**, которая показывает состояние гибридного инвертора **Deye** на сенсорном экране 320×240.

Устройство по Wi‑Fi опрашивает логгер Solarman инвертора (протокол **Solarman V5**, внутри Modbus RTU, TCP-порт 8899) и выводит данные на вкладки:

- **Battery**: SOC, напряжение, ток, мощность и температура батареи;
- **Grid**: напряжение и мощность сети, мощность нагрузки;
- **Solar**: напряжение, ток и мощность PV1/PV2, выработка за день;
- **Settings**: открывается долгим нажатием кнопки BOOT.

## Совместимость с инверторами

Прошивка разработана и проверена на **Deye SUN-5K-SG05LP1-EU**. Совместимость с другими моделями выведена из карты регистров и на железе не проверялась.

Прошивка читает один блок Modbus-регистров **103…191** в формате однофазных гибридов Deye (напряжение сети 150, мощность сети 169, нагрузка 178, батарея 182–184 и 190–191, PV 108–112 и 186–187). Кроме того, ответ отбрасывается при неправдоподобных значениях: напряжение батареи выше 70 В, мощность батареи или одной строки PV выше 15 кВт, ток строки PV выше 30 А. Эти пороги рассчитаны на систему 48 В мощностью до 12 кВт.

### Подходят

| Семейство | Примеры моделей | Замечания |
|---|---|---|
| Однофазные низковольтные гибриды Deye (батарея 48 В) | SUN-3.6K/5K/6K-SG03LP1-EU, **SUN-5K-SG05LP1-EU** (проверен), SUN-7.6K/8K-SG01LP1, SUN-xK-SG04LP1 | Должны работать без изменений |
| Американские split-phase той же серии | SUN-xK-SG01LP1-US | Напряжение сети показывается по одной фазе (~120 В) |
| Ребренды Deye с той же картой регистров | Sunsynk (однофазные гибриды), Sol-Ark 5K/8K/12K | Нужен логгер Solarman. Штатный донгл Sunsynk часто не поддерживает Solarman V5 |

Ограничения для этого семейства:

- **Больше двух MPPT** (старшие модели 10–16K): PV3/PV4 не отображаются, суммарная мощность солнца занижена.
- **Модели 14–16K**: мощность батареи на пике может превысить порог 15 кВт. Такие ответы будут отбрасываться, и показания на экране перестанут обновляться.

### Не подходят (без доработки)

| Семейство | Примеры моделей | Причина |
|---|---|---|
| Трёхфазные низковольтные гибриды | SUN-5…12K-SG03LP3 / SG04LP3-EU | Другая карта регистров (данные в диапазоне ~500–680) |
| Трёхфазные высоковольтные гибриды | SUN-xxK-SG01HP3-EU и др. | Та же карта, что у LP3, плюс батарея 160–800 В не проходит проверку «≤ 70 В» |
| Сетевые (стринговые) инверторы | SUN-xK-G, SUN-xxK-G03/G04 | Нет батареи, другая карта регистров |
| Микроинверторы | SUN600/800/1000G3 и др. | Другая карта регистров, нет батареи |

> ⚠️ На трёхфазном инверторе прошивка может показывать **правдоподобные, но неверные** числа. Ответ корректен по контрольным суммам, поэтому отбрасывается он только тогда, когда значения не проходят проверку правдоподобия.

### Требования к логгеру

Нужен Wi‑Fi/LAN-логгер Solarman (например, LSW-3, LSE), который отвечает по протоколу V5 на TCP-порту **8899** в локальной сети. У некоторых новых логгеров и прошивок этот порт закрыт, с такими прошивка работать не будет. Для настройки понадобятся IP-адрес логгера и его **серийный номер** (напечатан на корпусе стика).

## Оборудование

- Плата ESP32-2432S028 (CYD): дисплей ILI9341 320×240, тач XPT2046.
- Питание по USB.

## Сборка и прошивка

Проект собирается в [PlatformIO](https://platformio.org/), окружение `cyd`:

```
pio run -e cyd                 # сборка
pio run -e cyd -t upload       # прошивка
pio device monitor -b 115200   # serial-лог
```

## Первая настройка

1. При первом запуске плата поднимает точку доступа **`Deye_Monitor_ESP32_IoT`**.
2. Подключитесь к ней и в открывшемся портале выберите домашнюю сеть Wi‑Fi.
3. Укажите IP-адрес и порт логгера, его серийный номер, Modbus Slave ID (обычно 1), часовой пояс и флаг летнего времени.

Настройки хранятся в NVS и переживают перезагрузку. Поведение при пропадании света, перезагрузке и потере сети описано в [docs/behavior_scenarios.md](docs/behavior_scenarios.md).

## План: поддержка трёхфазных гибридов

Статус: **запланировано, не реализовано.** Цель — поддержать SUN-xK-SG03LP3/SG04LP3-EU (батарея 48 В) и SUN-xxK-SG01HP3-EU (высоковольтная батарея) с помощью выбираемого профиля инвертора.

Шаги (каждый отдельным изменением с проверкой сборки):

1. **Настройка «Профиль инвертора»**: `1-фазный LP1` (по умолчанию, текущее поведение) или `3-фазный LP3/HP3`. Добавляется по обычной цепочке: дефолт в `config.h`, затем `settingsLoad`/`settingsSave*`, затем поле в портале WiFiManager и на вкладке Settings.
2. **Карта регистров как структура профиля.** Адреса, начало и длину блока, масштабы вынести из констант `config.h` в описание профиля. Для профиля LP1 значения остаются прежними, поведение не меняется.
3. **Карта для трёхфазного профиля.** Предварительные адреса (сверить с документацией Deye перед реализацией): батарея 586–591 (температура, напряжение, SOC, мощность, ток), напряжение сети по фазам 598–600, мощность сети 625, нагрузка 653, мощность PV 672–673, напряжение и ток PV 676–679. Их можно прочитать одним блоком 586…679 (94 регистра). Выработка за день (529) лежит вне этого блока: либо второй запрос, либо на первом этапе не показывать.
4. **Пороги `checkPlausibility()` по профилю.** Для HP3 напряжение батареи до ~800 В, мощности до 30–50 кВт. Проверка закона Ома для батареи остаётся.
5. **Интерфейс.** На вкладке Grid показывать напряжение по трём фазам (при трёхфазном профиле).
6. **Проверка на железе.** Нужен владелец трёхфазного Deye, готовый прислать serial-лог. До такой проверки профиль помечается как экспериментальный.

Попутно (не относится к трёхфазным):

- показ PV3/PV4 для однофазных моделей с 3–4 MPPT (регистры уже входят в опрашиваемый блок);
- пороги правдоподобия для моделей 14–16K.
